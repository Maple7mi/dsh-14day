提示词怎么写

提示词是工作交办单：目标、背景、输入、约束、验收、输出格式。六格写满，普通模型也能干出专业活。

附录 A · 10 条原则 + 12 个模板 → 对应第 3–5 天
👥

什么叫 Agent Team

你带一个项目组：会话是 Lead，可以创建有名字的队友，队友共享一块任务板、能互相发消息，你只负责定目标和验收。

附录 B · 角色 / 工具 / 限制 / 示例 → 对应第 9–10 天
🧩

自带插件有什么

界面、能力、协作、实验四类，约 40 项能感知的功能；本机默认完全权限、插件市场默认没开——手册都标了。

附录 C · 分组目录 + 本机开关状态 → 对应第 6、12 天

两周，从「会用」到「会带」

第一周练个人生产力：界面 → 工作方式 → 提示词 → 长期记忆 → 插件技能 → 小项目。第二周练 AI 协作：子代理 → Agent Team → Workflow → 结营项目。

怎么用

每天三段，一天一个概念

读概念 20 分钟

先弄清为什么，再看界面长什么样。概念都配了类比，不需要编程基础。

动手 50 分钟

跟着步骤做，提示词直接复制、改方括号里的内容。每天都有一个能看见的产出（文件、网页、报告）。

打勾 10 分钟

对照「完成标准」逐条打勾，把坑记进笔记。做不到就回看，第二天先补练习再做新内容。

结营验收单

14 天后你会做到

  • 独立新建工作区、会话，用一句清楚的话让 DSH 完成一件真事
  • 写出带目标、背景、输入、约束、验收、输出格式的提示词
  • 会用 @ 引用文件、/plan 先计划、返工话术
  • 有一个自己的 AGENTS.md，让 DSH 记住你的规矩
  • 用 DSH 做过 Word / Excel / PDF 至少各一份
  • 亲手组建过一次 Agent Team（≥2 队友 + 共享任务板）并验收
  • 会用子代理并行调研，会用 Workflow 批量处理
  • 有一个发布到 GitHub 的作品
现在开始

今晚 10 分钟就能起步

  1. 建工作区：在 DSH 左侧栏「添加工作区」，选 E:\AI-Learning\DSH练习（没有就先建目录）。
  2. 发第一个任务：新开会话，粘贴手册第 1 天的「只读目录说明」提示词，等它产出 notes/day01.md。
  3. 看工作过程：点开它的工具调用卡片，看它读了几次、写了几次——这就是第 2 天要讲的内容。
